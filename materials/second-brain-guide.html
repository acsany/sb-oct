📖 What is second-brain?

Your Personal Note-Taking Companion

A simple, elegant CLI tool that captures your ideas as plain markdown files. No databases, no friction — just your thoughts saved in an organized way.

💾 Save notes with a single command
📋 List all your notes instantly
👀 View any note by its number
📁 Stored as YYYY-MM-DD-slug.md

⚡ Three Essential Commands

🆕 new

Create a new note with a title. Optionally add a multi-line body using --body or read from stdin.

Examples:

second_brain new "Caching idea" second_brain new "Idea" --body "Details here"

📋 list

Show all your notes in numbered order, newest first. Perfect for seeing what you've captured lately.

Output:

Notes: ~/second_brain/ 1. 2026-10-25-caching-idea.md 2. 2026-10-24-design-pattern.md

👀 show

Display the full contents of a note by its number from the list. Numbers match the output of list.

Example:

second_brain show 1

🚀 Getting Started

1️⃣ Installation

uv sync

2️⃣ Configure (Optional)

cp .env.example .env

3️⃣ Start Using!

uv run second_brain new "My idea"

📍 Where are notes saved?

By default: ~/second_brain/

You can change it by setting the SECOND_BRAIN_DIR environment variable.
